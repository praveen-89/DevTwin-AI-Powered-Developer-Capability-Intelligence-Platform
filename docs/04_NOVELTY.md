# 4. Novelty & Research Contribution

## Novelty Claims
DevTwin's proposed contribution is the integration of heterogeneous developer evidence into a longitudinal, explainable capability model that connects technical knowledge, real-world engineering behavior, engineering risk, capability gaps, intervention, and future capability state.

*Note: The Minor project establishes the foundation for this capability intelligence model by integrating GitHub-derived evidence, SkillGraph, CodeRisk, and explainable capability estimation.*

Unlike tools that treat codebase issues purely as repository debt, DevTwin maps engineering signals back to individual capability progression, enabling personalized learning interventions (StudyTwin) based on demonstrated gaps rather than arbitrary testing.

## Evidence-Backed Paradigm
By strictly enforcing the separation of Observation (immutable fact) and Evidence (contextualized weight), and calculating capability deterministically, DevTwin avoids the "black box" hallucination problem inherent in using pure LLMs for capability assessment.
